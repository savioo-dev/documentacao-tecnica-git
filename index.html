O que é Git

Git é um sistema de controle de versão distribuído criado por Linus Torvalds em 2005.

Ele permite rastrear alterações no código e colaborar com outras pessoas de forma segura.

Diferente de sistemas centralizados, cada desenvolvedor tem uma cópia completa do histórico.

git --version
Instalação

A instalação varia conforme o sistema operacional utilizado.

No Linux, geralmente basta usar o gerenciador de pacotes da distribuição.

  • Debian/Ubuntu: sudo apt install git
  • Fedora: sudo dnf install git
  • macOS: brew install git

Após instalar, configure seu nome e e-mail:

git config --global user.name "Seu Nome" git config --global user.email "voce@email.com"
Comandos básicos

Estes são os comandos mais usados no dia a dia com Git.

  • git init — inicializa um repositório
  • git add — adiciona arquivos ao stage
  • git commit — registra as alterações

Um fluxo típico de commit:

git add . git commit -m "mensagem"
Branches

Branches permitem desenvolver funcionalidades isoladamente.

A branch principal costuma se chamar main ou master.

  • git branch nova-branch — cria uma branch
  • git checkout nova-branch — alterna para ela
git checkout -b feature/login
Boas práticas

Commits pequenos e descritivos facilitam a revisão de código.

Nunca faça commit de segredos como senhas ou chaves de API.

Use um arquivo .gitignore para excluir arquivos desnecessários.

echo "node_modules/" >> .gitignore
